# Request for Investigation: Linux-Based Rufus Alternatives

## Priority

Very very low. Do not begin until a) an architect has assigned this to you and b) all RFSs that you could complete are done.
## Background

Currently, the LiDAR team uses a tool called Rufus to burn .iso files onto USB drives. However, Rufus only runs on Windows OS, which is a significant inconvenience for an Ubuntu-only team! 

## Information Requested

This RFI requests a thorough report on Linux-based alternatives to Rufus. It should include the following sections:

1. Search Methodology

2. Located tools that meet the criteria

    * Subsection 1...

    * Subsection 2...

3. Located tools that do not meet the criteria

    * Subsection 1...

    * Subsection 2...

4. Recommendation

5. Annotated Bibliography

Section 1 should describe how different tools were located (by LLM agent, Google Search, word-of-mouth, etc.)

Sections 2 and 3 should contain one subsection for each tool that was investigated. This subsection should be titled with the name of the tool, and include a detailed report on what the tool does. If the researcher concludes that the tool would meet the requirements of this RFI, then it should be included in Section 2. If the researcher investigated a tool that, upon closer examination, does not fully meet the criteria of this RFI, the researcher should still write about it, and include the writeup in Section 3. These writeups should err on the side of containing more information about each tool, and should include a detailed analysis of what the tool is, how it may be installed, its exact functionality, reports by the researcher who personally tested the tool to verify that it actually works as advertised, appropriate citations of all sources examined, etc.

Section 4 should recommend a tool that meets the specifications of this RFI, or state that after very extensive research, the researcher was unable to locate a tool that meets these specifications. 

Section 5 should list each source which the researcher read (a URL is sufficient), along with a brief summary of the information the source contained and the researcher's opinion on its usefulness. The researcher should list ALL sources consulted, whether or not they think that they ultimately were of value. It is recommended that the researcher write this portion of the report in real time, while conducting their research.


## Formating

The report should be written in well-formatted Markdown and be placed in the same directory as this RFI.
