# Idea

We thought it would be a good idea to make ~/Documents/Data an automatically updating git repo as a means of data storage.

# We tried...

1. Regular GitHub actually has a max file size limit, so we couldn't do that

2. There's a tool called Git-LFS (Large File Storage) that lets you store unreasonably large files in your GitHub repos. However, there's a max cap of a couple GB on that too

# We concluded...

1. GitHub was not the appropriate tool for the job

2. However, we do have access to a Box folder from Dr. Master. If we wanted to implement this kind of sync, we'd definitely need to contact him first, but it's more workable because it's Wheaton data storage with no file-size limit.
